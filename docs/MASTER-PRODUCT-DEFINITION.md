# Master Product Definition

**Status:** PROPOSED
**Authority:** Founder; `docs/product/FEATURE-BOUNDARIES.md` controls scope detail.

TalentisOS is a local-first leadership operating system. Its primary experience privileges End of Day, Morning Huddle, and Today’s Work; everything else is progressively disclosed.

| Module | Purpose | Boundary |
| --- | --- | --- |
| End of Day | Close the day and prepare carry-over | Not a time tracker or journal archive. |
| Morning Huddle | Align the day’s focus | Not a meeting/chat system. |
| Today’s Work | Present actionable current work | References canonical tasks; never clones them. |
| Tasks / Subtasks | Canonical actionable work | Not a full project-management suite. |
| 30-60-90 Roadmap | Guide leadership onboarding and growth | Not a performance dossier. |
| KPIs / Scorecards | Review measures and corrective actions | Not surveillance or compensation scoring. |
| Rocks / Priorities | Maintain focused priorities | Not a portfolio-management tool. |
| Issues / IDS / 5 Whys | Move issues to a practical action | Not lengthy project reporting. |
| Meetings | Link meeting outcomes to actions | Not conferencing or messaging. |
| Praise, Feedback, Coaching, Delegation, Expectations, Difficult Conversations | Support leadership conversations | No disciplinary or protected-person data. |
| Risks, Blockers, Decisions | Make impediments and choices visible | Not enterprise risk/compliance management. |
| Improvements / Kaizen | Support lightweight PDCA improvement | Not bureaucracy. |
| SOPs, Playbooks, Frameworks | Retain practical standards | No copied proprietary material. |
| Analytics | Offer leadership insights | No employee surveillance. |
| Templates | Start guided workflows | Must preserve canonical data rules. |
| Settings | Local preferences and workday configuration | `localStorage` only for non-critical preferences. |
| JSON Export / Import | User-controlled portability and recovery | Must validate, version, and never silently corrupt data. |

The 30-60-90 progression is Learn & Stabilise (days 1–30), Align & Improve (31–60), then Scale & Lead (61–90): **Foundation → Relationship → Feedback → Coaching → Delegation → Accountability → Leadership Maturity**.
