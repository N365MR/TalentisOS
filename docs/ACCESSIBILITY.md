# Accessibility

Use semantic landmarks, one descriptive page heading, logical heading order, keyboard access, visible focus indicators, sufficient color contrast, reduced-motion support, and labels that make sense without visual context.

Navigation must work with keyboard and touch. Status changes should use appropriate live-region semantics. Forms in later phases must associate labels, errors, instructions, and required states programmatically. Validate with keyboard-only checks, screen-reader spot checks, responsive zoom, and automated linting.
