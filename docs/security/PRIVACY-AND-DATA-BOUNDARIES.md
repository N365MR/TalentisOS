# Privacy and Data Boundaries

**Status:** PROPOSED
**Authority:** Founder

TalentisOS is local-first: no login, account, external API, third-party database, or internet connection is required for core operation. Core leadership data remains on the user’s device by default.

It must not store medical/health information, payroll, disciplinary records, protected characteristics, surveillance information, confidential HR files, or recruitment information. Leadership records favour generic role, function, team, action, expectation, and coaching topic. Any request to expand these boundaries requires change control and Founder approval.
