# Definition of Done

**Status:** PROPOSED
**Authority:** Founder

A phase is done only when applicable requirements, UX, responsive behaviour, persistence, navigation, accessibility, empty/error/edge states, duplicate prevention, migrations, and privacy/security controls are complete; no console errors, uncaught promises, or unexplained warnings remain; tests pass; documentation, status, and decision records are current; the diff is reviewed; the work is committed and pushed; and Founder acceptance is recorded.
