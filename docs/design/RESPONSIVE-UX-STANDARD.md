# Responsive UX Standard

**Status:** PROPOSED
**Authority:** Design authority

Validate representative widths of approximately 375px (iPhone), 768px (iPad), and 1280px+ (desktop), in portrait/landscape where relevant. Use dynamic viewport units, flexible grids, readable line lengths, and touch targets at least 44×44 CSS pixels where practical. Critical actions remain reachable without hover.

Use space deliberately: mobile prioritises focus, tablet adds contextual grouping, desktop adds efficient multi-column context. Test browser zoom, long labels, keyboard focus, empty/error states, and dialogs at constrained heights.
