# Information Architecture

**Status:** PROPOSED
**Authority:** Founder; design authority

The application shell privileges three primary daily destinations in this order: End of Day, Morning Huddle, Today’s Work. Supporting systems are grouped behind progressive disclosure and contextual actions, rather than presented as equal global navigation.

First run explains the daily rhythm and offers one clear entry. Empty states state purpose, absence, and the smallest meaningful next action. Utility surfaces include settings, export/import, and help. Dialogs are for focused, reversible decisions: fit the viewport, use logical sections, retain a clear exit, do not nest, and avoid long internal scrolling or desktop full-screen presentation unless content requires it.

Mobile uses compact primary navigation and touch-sized actions; tablet uses available width for context; desktop may show persistent navigation and context, not an enlarged phone layout.
