# Design System

**Status:** PROPOSED
**Authority:** Founder; design authority

Visual direction is calm, dark, precise, spacious, and premium. Canonical tokens: `--background #070A0F`, `--surface #10151D`, `--elevated #151B24`, `--border #263241`, `--text-primary #F7FAFC`, `--text-secondary #9BA7B4`, `--text-muted #66737F`, `--accent-teal #23E0C5`, `--cta-blue #2F80FF`, `--warning #F5A524`, `--danger #FF4D4F`, `--success #24D18F`.

Use clear typography, generous whitespace, rounded surfaces, restrained bento cards where justified, concise labels, meaningful icons, strong hierarchy, lightweight status, subtle motion, and reduced-motion support. Avoid beige, excessive gradients/shadows/cards, visual noise, giant forms, decorative animation, and modal overload.
