# Accessibility Standard

**Status:** PROPOSED
**Authority:** Design authority

TalentisOS follows a WCAG-oriented baseline: semantic landmarks, logical headings, native controls before ARIA, accessible names, visible focus, keyboard operation, sufficient contrast, screen-reader-friendly status/error messages, and mobile-sized touch targets.

Respect `prefers-reduced-motion`; never require animation, color alone, hover, or precise pointer movement to complete a task. Validate phone, tablet, desktop, zoom, and portrait/landscape conditions. Use ARIA only when semantic HTML is insufficient.
