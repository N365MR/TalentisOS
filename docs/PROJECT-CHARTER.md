# Project Charter

**Status:** PROPOSED
**Authority:** Founder; governed by `docs/governance/PROJECT-GOVERNANCE.md`

## Purpose

TalentisOS is **Your Daily Leadership Playbook**: a minimalist, visual, local-first operating system that turns leadership into a practical daily rhythm.

## Users, problem, and value

It serves leaders who need a clear next action rather than another administrative system. It reduces fragmented planning by carrying one canonical record through the day: **Capture once. Carry forward. Act. Complete.**

## Operating model

Daily flow: **End of Day → Morning Huddle → Today’s Work**. Leadership rhythm: **Prepare → Align → Execute → Review → Improve**. Product philosophy: **Lead the day before the day leads you.**

## Scope and exclusions

TalentisOS supports leadership practice, not general project administration. It excludes HRIS, CRM, ERP, payroll, recruitment, employee surveillance, time tracking, messaging, and punitive ranking. It is local-first and must not require an account or cloud service for core use.

## Success criteria

The product makes a leader’s immediate focus clearer, preserves context without duplicate entry, works on phone/tablet/desktop, and keeps operational data on-device by default.

## Founder authority

The Founder approves phase transitions and material decisions affecting architecture, scope, data, design, terminology, privacy, and non-negotiable principles. Code alone is not approval.
