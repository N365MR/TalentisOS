# Design System

The interface should feel calm, focused, and useful at the start and end of a workday. Prefer clear hierarchy, generous spacing, restrained color, short labels, and progressive disclosure.

Use semantic HTML, visible focus states, readable contrast, responsive layouts, and touch targets suitable for iPad. Each screen has one primary action; supporting actions are visually subordinate.

The foundation uses a deep blue for navigation and headings, pale blue-gray surfaces, white content cards, and teal for positive status. Avoid decorative dashboards, dense tables, and attention-grabbing motion.
