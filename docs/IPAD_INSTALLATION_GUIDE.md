# iPad Installation Guide

1. Open the live TalentisOS URL in Safari: <https://n365mr.github.io/TalentisOS/>.
2. Wait for the app to load completely while online.
3. Tap the **Share** button.
4. Select **Add to Home Screen**.
5. Confirm the name **TalentisOS**.
6. Tap **Add**.
7. Open TalentisOS from the Home Screen.
8. Complete onboarding.
9. Create a test priority or work item.
10. Close and reopen the app from the Home Screen.
11. Enable Airplane Mode to test offline mode.
12. Confirm the app opens and the test data remains available.
13. Disable Airplane Mode after testing.

Data remains on the iPad unless deliberately exported. Use Settings → Data to export a JSON backup before clearing Safari website data or moving to another device. The app supports portrait, landscape, Split View, Stage Manager, dark mode, iPad Files import, and the native share/download interface where available.
