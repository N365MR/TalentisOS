# iPad Installation Guide

1. Open the deployed TalentisOS URL in Safari on iPad.
2. Tap Share, then choose **Add to Home Screen**.
3. Confirm the name and tap **Add**.
4. Open TalentisOS from the Home Screen for the standalone PWA experience.

The app shell is designed for touch and responsive layouts. In a later phase, verify that locally stored data remains available after offline use and that users understand browser/site-data clearing can remove local records.
