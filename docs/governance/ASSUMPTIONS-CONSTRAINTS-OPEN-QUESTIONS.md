# Assumptions, Constraints, and Open Questions

**Status:** PROPOSED
**Authority:** Founder

## Assumptions

- Default leadership workweek is Monday–Friday; workdays may later be configurable.
- The browser provides IndexedDB and PWA capability; unsupported capability is surfaced safely.
- The user controls export files and local-device backups.

## Constraints

- Vite + Vanilla JavaScript ES modules + semantic HTML + modern CSS only, unless Founder-approved.
- Static GitHub Pages-compatible deployment; no backend, cloud database, tracker, or third-party authentication.
- No substantive product feature in Phase 00.

## Open questions

- Founder approval is required for Phase 00.
- Remote GitHub authentication/access must be restored before the baseline can be pushed and verified.
- Later phases must decide configurable workdays, retention/archiving policy, and JSON duplicate-resolution UX.
