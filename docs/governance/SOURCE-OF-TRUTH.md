# Source of Truth

This canonical documentation hierarchy is: Founder-confirmed decisions, this governance set, product/design/engineering documents, phase records, then historical audits and playbooks. Code implements rather than overrides this hierarchy.

When an older TalentisOS-X specification conflicts with a later Founder-confirmed decision, the later confirmed decision takes precedence. The canonical documentation must then be updated so the repository reflects the current decision rather than preserving conflicting requirements indefinitely.

Historical material in the repository is retained as context only and is not authoritative where it conflicts with these documents.
