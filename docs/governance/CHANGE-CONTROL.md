# Change Control

**Status:** PROPOSED
**Authority:** Founder

After Phase 00 is approved, changes to architecture, scope, data, terminology, design, core behaviour, privacy, or non-negotiable principles require a `CHG-####` record. It must state the requested change, reason, affected baseline/requirements, data/UX/migration/testing impact, risks, decision, and Founder approval.

Unapproved deviations are not implementation permission. Emergency containment may be taken only to prevent data loss or security harm, then must be escalated and recorded immediately.
