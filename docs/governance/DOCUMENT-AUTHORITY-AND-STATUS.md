# Document Authority and Status

**Status:** PROPOSED
**Authority:** Founder

The approved TalentisOS documentation inside the canonical repository is the authoritative product and engineering source of truth.

Document statuses are **DRAFT**, **PROPOSED**, **APPROVED**, **BASELINED**, **SUPERSEDED**, and **RETIRED**. Every controlling document identifies its status and authority.

Conflict precedence is: (1) an explicit later Founder-approved decision; (2) an approved change record; (3) latest approved/baselined controlling document; (4) earlier approved document; (5) implementation; (6) draft documentation; (7) informal conversation.

When a confirmed TalentisOS decision changes architecture, module behaviour, data model, design system, terminology, privacy boundary, or another non-negotiable rule, authoritative documentation must be updated. A later formally approved decision overrides an older conflicting specification.
