# Project Governance

**Status:** PROPOSED
**Authority:** Founder

The Founder is the decision, design, architecture, and phase-approval authority. A delivery owner may propose work and record evidence, but cannot self-approve a phase.

Material decisions require a decision-log entry and Founder approval: architecture, scope, canonical data model, design system, terminology, privacy/security boundary, and product principles. Exceptions or deviations require the same record plus impact, mitigation, expiry/review date, and escalation to the Founder.

Evidence for a phase includes requirements traceability, tests/build output, manual validation notes, reviewed diff, documentation updates, commit SHA, push confirmation, and explicit Founder acceptance. Code does not make a product decision canonical.
