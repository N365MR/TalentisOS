# Product Principles

**Status:** PROPOSED
**Authority:** Founder

1. **Simplicity:** reduce taps, forms, duplication, settings, and competing hierarchy.
2. **Leadership before project management:** stay a leadership operating system.
3. **Capture once:** reuse canonical entities through references.
4. **Guidance before administration:** answer “what next?” first.
5. **Coaching before scoring:** help leaders improve; do not rank people punitively.
6. **Local-first privacy:** core use requires no account, external API, or cloud data store.
7. **Responsive first:** primary interactions work at phone, tablet, and desktop widths.
8. **Improve deliberately:** **Simplify → Standardise → Stabilise → Measure → Improve → Automate**.

These principles are binding until changed through approved change control.
