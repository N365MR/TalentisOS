# Build Phases

## Foundation (complete)

Vite vanilla JavaScript project, semantic shell, five navigation areas, PWA manifest and service worker, documentation, quality scripts, and GitHub Pages build path.

## Phase 1

Implement the smallest useful Today, Huddle, Work, Review, and Improve flow with IndexedDB persistence, one primary action per screen, and no employee or HR entities.

## Later phases

Add carefully scoped import/export, stronger offline update handling, accessibility hardening, and user-requested refinements. Do not add features from excluded product categories or build future phases prematurely.
