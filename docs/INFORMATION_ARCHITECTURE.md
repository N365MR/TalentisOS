# Information Architecture

The top-level navigation is intentionally limited to five areas:

1. Today — current priorities and attention signals.
2. Huddle — morning alignment and preparation.
3. Work — focused commitments and follow-up.
4. Review — end-of-day closure and tomorrow preparation.
5. Improve — operating lessons and experiments.

The shell should keep the current context visible, preserve a predictable back path, and avoid nested navigation unless a later phase demonstrates a real need. A screen must present one primary action.
