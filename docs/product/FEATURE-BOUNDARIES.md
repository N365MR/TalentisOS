# Feature Boundaries

**Status:** PROPOSED
**Authority:** Founder

TalentisOS supports practical leadership rhythm. It is not Jira, Monday.com, Asana, Microsoft Project, ERP, HRIS, CRM, payroll, recruitment, surveillance, time tracking, or messaging software. Feature proposals must improve leadership focus, reuse canonical information, respect privacy, and be authorised by the current phase; otherwise they are deferred.
