# Product Principles

- Action before administration
- Capture once
- One source of truth
- Guidance before configuration
- Exceptions deserve attention
- Coaching over punishment
- Progressive disclosure
- Mobile-first leadership
- Local-first privacy
- Continuous improvement

The improvement sequence is: **Simplify → Standardise → Stabilise → Measure → Improve → Automate**.

Feature decision filter: add a feature only when it materially supports a leadership action, records information once in the canonical place, respects local-first privacy, and is appropriate to the approved phase. Otherwise defer it.
