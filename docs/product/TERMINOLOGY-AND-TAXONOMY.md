# Terminology and Taxonomy

**Status:** PROPOSED
**Authority:** Founder

| Term | Canonical meaning |
| --- | --- |
| Task / Subtask | Canonical actionable record / its child action. |
| Top 3 | The three most important current actions. |
| Carry-over | A reference/history movement to a later workday, never a clone. |
| Morning Huddle / End of Day / Today’s Work | Daily align / close-and-prepare / execute surfaces. |
| Rock / KPI / Scorecard | Focused priority / measure / its review surface. |
| Issue / IDS | Problem record / Identify-Discuss-Solve method. |
| Risk / Blocker / Waiting | Potential harm / current impediment / externally pending state. |
| Decision / Action | Recorded choice / accountable follow-up. |
| Improvement / SOP / Playbook / Framework | PDCA change / standard procedure / practical guide / reusable approach. |
| Meeting / Roadmap / Owner / Due / Completed | Collaboration session / time-bound progression / accountable person / local deadline / completion state. |
| On Track / At Risk / Off Track / Not Reported | KPI states; an Off Track KPI must support a corrective action. |
