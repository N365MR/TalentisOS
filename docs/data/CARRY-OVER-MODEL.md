# Carry-Over Model

**Status:** PROPOSED
**Authority:** Founder

Carry-over preserves raised/created/updated/due/completed dates, age, carry count, blocked/waiting state, movement history, and EOD/Huddle appearances. Showing a task on another day never resets its age.

The default next-workday rule is Monday→Tuesday, Tuesday→Wednesday, Wednesday→Thursday, Thursday→Friday, Friday→Monday. No weekend Huddle record is created unless the user deliberately chooses it. Future workdays may be configurable.
