# Security and Privacy

Local-first is a product principle: user data stays in the browser’s IndexedDB unless the user explicitly exports it. There are no accounts, backend services, cloud databases, third-party analytics, advertising pixels, or trackers.

Phase 2 stores only leadership rhythm preferences, daily plan state, and priority records in the local IndexedDB database. Onboarding deliberately excludes employee names, employee details, organisational hierarchy, HR information, and performance information.

Minimize data collection, avoid sensitive personal data, validate imported data, use safe DOM APIs, and keep dependencies small and reviewed. Explain clearing site data and export behavior clearly. The product must not create employee profiles or hold HR, performance, payroll, recruitment, surveillance, or time-tracking data.
